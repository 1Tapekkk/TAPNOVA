## TAPNOVA 4.1.0

### Pobierz i uruchom

- **Windows 10/11, 64-bit:** pobierz `TAPNOVA-4.1.0-win-x64.exe` i uruchom instalator.
- **Mac z M1/M2/M3/M4 lub nowszym procesorem Apple:** pobierz `TAPNOVA-4.1.0-mac-arm64.dmg`.
- **Mac z Intelem:** pobierz `TAPNOVA-4.1.0-mac-x64.dmg`.
- Na Macu otwórz DMG i przeciągnij TAPNOVA do Applications (Aplikacje). Wymagany macOS 13 lub nowszy. ZIP jest alternatywą dla DMG.
- Nie trzeba pobierać „Source code”, instalować Node.js ani GitHub Desktop.

### Nowe funkcje

- Komentarze własnego statusu: lista, wyszukiwarka, wybór komentarzy i usuwanie po potwierdzeniu. Poprawiony format zapytań API i dokładniejsze komunikaty błędów.
- Mój pulpit: wyszukiwarka narzędzi, ulubione i zmiana ich kolejności; Ctrl+K lub Cmd+K.
- Lokalne archiwum komentarzy przed usunięciem, eksport JSON i dziennik zadań, osobno dla konta.
- Zdjęcia gry: aparat lub Ctrl+Shift+S / Cmd+Shift+S, odliczanie i chwilowe ukrycie panelu TAPNOVA.
- Czytelniejsze okna i obsługa klawiatury, także na małych ekranach.

### Instalacja i weryfikacja

Paczki nie mają certyfikatu wydawcy. macOS ma podpis techniczny ad-hoc, bez notaryzacji Apple; system może zablokować pierwsze uruchomienie. Jeśli ufasz temu wydaniu, skorzystaj z „Otwórz mimo to” w Ustawieniach systemowych → Prywatność i ochrona. Nie wyłączaj Gatekeepera. Windows może wyświetlić SmartScreen.

Wydanie jest publikowane dopiero po testach i uruchomieniu paczki na Windows, macOS Intel i macOS Apple Silicon w GitHub Actions. Testy gry używają symulowanej sesji; nie potwierdzają wszystkich operacji na żywym koncie. Serwer i klient gry decydują, czy u innych graczy pozostaje ślad usuniętego komentarza.

Archiwum i dziennik są lokalne. Przy aktualizacji zamknij poprzednią aplikację; nie trzeba usuwać danych profilu. Szczegóły zawiera `INSTRUKCJA.md`, a sumy plików — `SHA256SUMS.txt`.
