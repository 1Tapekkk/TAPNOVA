# TAPNOVA 4.2.1

- Licencje działają przez publiczny serwer Cloudflare. Komputer twórcy nie musi być uruchomiony, aby aktywować aplikację.
- Wersje Windows, macOS Intel i macOS Apple Silicon korzystają z tego samego serwera HTTPS. Wymagane są ważny kod oraz internet.
- Panel właściciela obsługuje generowanie kodów, terminy ważności, limity urządzeń, reset i blokowanie licencji. Weryfikacja odbywa się po stronie serwera.
- Zachowano aktualizacje z aplikacji: Windows pobiera aktualizację i uruchamia instalację; macOS pobiera i otwiera DMG do ręcznej instalacji.

Jeśli korzystasz z lokalnej wersji testowej z adresem 127.0.0.1, zainstaluj tę wersję i ponownie wpisz swój kod. Użytkownicy 4.1.0 muszą wykonać tę aktualizację ręcznie; od 4.2 dostępny jest mechanizm kolejnych aktualizacji w aplikacji.

Pliki: EXE dla Windows x64, DMG/ZIP dla macOS Intel i Apple Silicon. Mac wymaga macOS 13 lub nowszego. Paczki mają dotychczasowe ograniczenia podpisu: brak certyfikatu Windows i brak notaryzacji Apple. Wydanie jest publikowane dopiero po testach wszystkich trzech platform.
