# TAPNOVA 4.2.4

- macOS: wyjaśnienie okna „TAPNOVA Safe Storage” i przycisk **Odczytaj zapisaną aktywację**. Chodzi o hasło pęku kluczy „Logowanie”, zwykle hasło do konta na Macu, nie kod TAPNOVA.
- Okno aplikacji jest wyświetlane przed odczytem magazynu systemowego. Odczyt i zapis korzystają z asynchronicznego safeStorage, aby nie blokować głównego wątku podczas pytania o zgodę.
- Po odmowie lub błędzie dostępu można ponowić odczyt. Aplikacja nie zastępuje nieodczytanej aktywacji nowym identyfikatorem urządzenia i nie zużywa dodatkowego miejsca w licencji.
- Zapis aktywacji jest atomowy. Błąd szyfrowania nie nadpisuje poprzedniego pliku. Można dokończyć zapis tokena po przerwaniu aktywacji bez ponownego tworzenia urządzenia.
- Zachowana zgodność z zaszyfrowanymi aktywacjami z wcześniejszych wydań; dodane testy migracji i odmowy dostępu.

Windows: aktualizacja przez aplikację po zatwierdzeniu. macOS Intel / Apple Silicon: pobierz DMG, zamknij TAPNOVA i zastąp aplikację w Aplikacjach. Wydanie nadal jest podpisane ad-hoc; macOS może ponownie zapytać o dostęp do pęku kluczy po aktualizacji.

Bot Discord ma już poprawioną publikację zdjęć oraz polskie powitania na Cloudflare. To zmiany serwerowe, niezależne od instalatora. Powitania sprawdzają dołączenia co minutę i nie wymagają włączonego komputera właściciela.

Testy nie wydają diamentów i nie usuwają rzeczywistych komentarzy. Warunki oraz dostępność funkcji gry pozostają zależne od API MSP2.
