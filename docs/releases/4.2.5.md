# TAPNOVA 4.2.5

## Uruchamianie MSP2

- Widok gry jest pokazywany przed rozpoczęciem nawigacji. Wcześniejsze pokazywanie dopiero po załadowaniu dokumentu mogło uruchamiać obsługę `visibilitychange` w Nebula, zanim gra przygotowała tłumaczenia, i powodować błąd `loading_resumed`.
- Nieudane otwarcie chowa widok gry i pozostawia możliwość ponowienia.
- Poprawka nie wyłącza komunikatów błędów ani nie zmienia plików gry, konta czy zapisanej sesji.

## Sprawdzenie

Test regresji w Electronie odtwarza przedwczesne powiadomienie o widoczności przy brakujących tłumaczeniach. Stara kolejność powoduje błąd; nowa przechodzi test. Test korzysta z lokalnej strony zastępczej, bez logowania do konta MSP2. Poprawka dotyczy kolejności otwierania w TAPNOVA, nie wszystkich możliwych błędów ładowania po stronie gry.

Windows: instalator EXE. macOS: DMG arm64 dla Apple Silicon lub x64 dla Intel. Aktualizacja macOS nadal wymaga otwarcia instalatora i zastąpienia aplikacji.
