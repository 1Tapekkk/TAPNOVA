# TAPNOVA 4.3.1 — poprawka uruchamiania MSP2

- Podczas uruchamiania gry aplikacja korzysta bezpośrednio z sieci Chromium. Obsługa lokalnego panelu konta nie przechwytuje już pobierania plików Unity, przekierowań ani połączeń gry.
- Panel konta bez uruchamiania gry nadal jest dostępny; jego obsługa sieciowa jest włączana tylko na czas korzystania z panelu.
- W ustawieniach dodano „Napraw wczytywanie”: zatrzymuje grę, czyści cache HTTP i uruchamia MSP2 ponownie. Nie usuwa ciasteczek, licencji ani ustawień konta.
- Zachowano poprawkę uruchamiania widocznego okna gry, która zapobiegała błędowi `loading_resumed`.

Jeżeli gra zatrzymywała się podczas ładowania, zaktualizuj aplikację i wybierz **Ustawienia → Napraw wczytywanie**.

Weryfikacja obejmuje automatyczne testy aplikacji, przejść między panelem konta a grą oraz zachowania ciasteczek i ustawień po naprawie. Testy korzystają z kontrolowanych odpowiedzi sieciowych; pełne ładowanie Unity po zalogowaniu na rzeczywiste konto wymaga potwierdzenia u użytkownika.
