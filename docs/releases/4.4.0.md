# TAPNOVA 4.4.0

- Zapisane profile kont: nick i region, wybór profilu, usuwanie oraz przełączanie po ponownym logowaniu. Hasła i tokeny MSP2 nie są zapisywane.
- Informacje o dostępności narzędzi w bibliotece. Rozmowy i ochrona wymagają uruchomionej gry oraz pokoju.
- Historia błędów w ustawieniach aplikacji. Po błędzie ładowania lub zamknięciu procesu można ponownie otworzyć grę.

Instalatory nadal nie mają certyfikatu wydawcy. Testy automatyczne używają środowisk testowych; nie potwierdzają działania każdej funkcji na rzeczywistym koncie MSP2.
